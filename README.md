# Блог на поток · ALPHA4

Сайт мастер-группы. Открыт по адресу https://silendmm-hub.github.io/blog-na-potok/

Всё в одном файле `index.html`, картинки в `img/`.
Настройки в самом конце `index.html`, блок «НАСТРОЙКИ»:
- `DEADLINE` — когда заканчивается скидка (время по UTC, по Москве +3 часа);
- `SEATS_TOTAL` и `SEATS_LEFT` — сколько мест всего и сколько свободно;
- `PAY_URL` и `PAY_URL_AFTER` — ссылки на оплату до и после окончания скидки.
